# 山むき・データビューワ

[リポジトリのREADMEに戻る](../README.md)

山むきの地点JSON、森林・水域・陰影などの地表SQLite、標高を収録した地形SQLiteを表示できる、WindowsとmacOS（Apple Silicon）向けのアプリ。地形の起伏を3D表示し、その上に地理院地図・OpenStreetMap系のオンライン地図や地表データを重ねられる。地点・地表・地形のローカルデータはオフラインでも利用できる。

| ソースのビルド・テスト・性能診断・Release公開 | [開発・検証・公開](docs/development.md) |
| 地形メッシュ・LOD・補間・合成・キャッシュの仕組み | [描画とデータ処理](docs/rendering.md) |

## 起動

配布ZIPを展開し、Windowsでは`yamamuki-viewer.exe`、macOSでは`YamamukiViewer.app`を開く。

ソースから起動する場合、Windowsでは`viewer\run_win.bat`を使える。Rustなどの準備とmacOSでの起動は[開発環境と起動](docs/development.md#開発環境と起動)を参照。コマンドはリポジトリのルートから実行する。

```sh
cargo run --locked --release --manifest-path viewer/Cargo.toml
cargo run --locked --release --manifest-path viewer/Cargo.toml -- points/gsi-peaks/gsi-peaks-source.json
cargo run --locked --release --manifest-path viewer/Cargo.toml -- --terrain build/terrain/gsi-terrain.sqlite3
```

## データを開く

ツールバーでファイルの種類に合うボタンを選ぶ。ファイルをウィンドウへドロップしても開ける。

| ボタン | 開くデータ | 表示内容 |
|---|---|---|
| 地点ファイルを開く | `.json`、`.json.gz` | 地点の丸印・名前・一覧・詳細 |
| 地表SQLiteを開く | 地表データを収録したSQLite | 森林・水域・陰影・地図画像など |
| 地形SQLiteを開く | 地形データを収録したSQLite | 標高による地形の起伏 |

地点は[版6](../points/schemas/data-v6.schema.json)と[版5](../points/schemas/data-v5.schema.json)に対応する。地表と地形のSQLiteは内容から種類を判別する。収録形式は[地表](../surface/formats/sqlite.md)・[地形](../terrain/formats/sqlite.md)、データの生成手順は[地表データ](../surface/README.md)・[地形データ](../terrain/README.md)を参照。

### 統合 SQLite を開く

地形を表示するには、対応する地形データセットが1件のファイルを開く。同じファイルに対応する地表データがあれば、地形に重ねて表示する。地点も重ねる場合は、地点JSONまたは地点SQLiteを別に開く。地形と同じファイルに収録された地点は、地形を開く操作では読み込まれない。

## マップの基本操作

| 操作 | 俯瞰視点での動作 |
|---|---|
| 左ドラッグ | 地図を移動 |
| 右ドラッグの左右 | 方位を回転 |
| 右ドラッグの上下 | 視点を傾ける |
| ホイール | カーソル位置を中心に拡大・縮小 |
| コンパスをクリック | 北を上にした真上視点へ戻る |
| 地図をクリック | 緯度・経度と、取得できる場合は標高を表示 |

座標ラベルの「コピー」で、緯度・経度をカンマ区切りでクリップボードへコピーできる。地点の丸印をクリックすると一覧の地点を選び、名称・座標・標高などを表示する。マップ右上には、現在操作できる視点切り替えボタンだけをコンパスの左側に表示する。

## レイヤー一覧

左ペインで、オンライン地図・開いた地点・地表・地形を操作する。親項目のチェックで配下をまとめてON/OFFできる。無効な項目でも「i」から情報を確認できる。

### オンライン地図

「オンライン地図」にチェックを付け、国土地理院またはOpenStreetMap系から下地を1種類選ぶ。標準地図・淡色地図・写真などを切り替えられ、次回起動時も選択を保持する。地図ごとのLOD欄で「自動」または提供元が対応する固定zレベルを選べる。

出典は[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)と[© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)など。表示中の地図の出典を画面下部に示す。ディスクキャッシュと配信元の利用条件は[キャッシュの説明](docs/rendering.md#ディスクgpuキャッシュと起動準備)を参照。

### 地表SQLite

別の地表SQLiteを開くとレイヤー一覧へ追加され、読み込み済みの地表も表示したままになる。データセット名のチェックで全体を、子項目のチェックで各レイヤーをON/OFFする。子項目ごとに自動・固定LODを選べる。

複数の地表は後から開いたファイルが上に重なる。ファイル内のレイヤーはデータに記録された描画順で合成する。「i」でファイル名・メタデータ・レベル別のタイル数や容量を確認でき、「閉じる」で取り除く。

### 地形SQLite

地形は標高と形状を持ち、地表は森林・水域などの見た目を持つ。地形を開くと、同じマップ領域に起伏を表示する。オンライン地図だけを貼ることも、オンライン地図をOFFにして地表SQLiteと組み合わせることもできる。

地形の1行目に表示チェック・名前・「i」・「閉じる」、2行目に自動・固定LODの選択を表示する。「i」では出典・データ版・形式版・レベル別のタイル数や標高点数・容量を確認できる。「閉じる」で地形を取り除いても、地表や地点と現在の視点は維持する。

## 地点一覧と詳細

[Web版の地点ビューワ](../points/viewer.html)と同様に、地点名・読み・別名・IDで検索し、タグ、出典、取得元での分類、標高の出典はそれぞれ複数選択できる。同じタグ欄ではいずれかに一致し、検索語とタグ条件は両方に一致する地点を表示する。絞り込み対象外の地点は小さな灰色マーカーで残る。マーカーの大きさはズームと絞り込み後の件数で切り替わる。2万地点以上のファイルは、表示範囲に入る地点から最大1万件を個別表示する。検索や条件解除で地図の縮尺は変わらない。

一覧を選ぶと、その縮尺のまま地図の中心と詳細が切り替わる。一覧にフォーカスがあるときは上下キーでも移動できる。地図で選んだ地点が一覧にある場合はその行までスクロールする。一覧は番号、地点名、標高、所在地（参考）、緯度・経度、よみがな、別名、タグ、SVG、IDの10列。見えている行だけを描画し、列見出しから並び替えられる。横スクロールと列幅調整で右側の列を表示できる。

地点の詳細では出典、取得元での分類、標高の出典、関連ID、タグ、別名、SVG、元のJSONを表示する。「近くの山」は直線距離が近い20地点を表示し、選んだ地点へ移動できる。所在地は座標からの参考判定。行政区域は国土交通省の国土数値情報を共同通信社が加工した[行政区域データ](https://github.com/kyodo-official/japan-choropleth#行政区域)を取得する。

「設定」の「地点」タブの「地点名を常時表示」で、丸印の横に名前を表示できる。名前が重なる箇所は選択地点などを優先して省略し、丸印の表示は維持する。この設定は次回起動時も保存する。

## 表示設定

ツールバーの「設定」でタブを切り替える。

| タブ | 主な設定 |
|---|---|
| オンライン地図 | 自動LODの上限・選択基準、拡大補間、レベル切り替えアニメーション |
| 地表 | 配色、自動LODの上限・選択基準、拡大補間、レベル切り替えアニメーション |
| 地形 | 自動LODの上限・精細度、傾き調整、境界接合、ワイヤーフレーム |
| 地点 | 地点名の常時表示 |
| 地点視点 | 景色モードでの加算する高さ・視野角 |
| 描画 | 垂直同期（VSync） |

自動LODは表示倍率に応じてデータの細かさを選ぶ。上限と選択基準はオンライン地図・地表・地形で別々に設定できる。レイヤー一覧の固定LOD指定を優先する。地表の配色は「データの既定色」「深緑」「淡色」「高コントラスト」「落ち着いた色」から選べる。

拡大補間は「輪郭優先」「バイリニア」「最近傍」「Bicubic」「Bスプライン」から選べる。オンライン地図と地表で別々に指定できる。補間方式の詳細は[画像の拡大補間](docs/rendering.md#画像の拡大補間)を参照。

設定ウィンドウの各タブにある「このタブを初期値に戻す」は、そのタブの表示項目だけを初期化する。他タブの設定、読込ファイル、現在の視点、レイヤー一覧の固定レベル選択は維持する。

設定の「描画」タブで「垂直同期（VSync）を待つ」を切り替えられる。初期値はOFF。画面提示モードはウィンドウ作成時に決まるため、変更は再起動時に反映する。設定はアプリの保存先の `graphics.json` に保存する。

オンライン地図と地表は、それぞれ「設定」内の「レベル切り替えをアニメーション」でクロスフェードをON/OFFできる。既定は両方ON。設定は再起動と表示スナップショットに保存し、この項目を持たない旧設定はONとして読む。OFFにすると進行中のフェードも終了し、次の画像が準備できるまでは現在の画像を維持する。オンライン地図は、新しいタイルを先に表示して同じ画像同士をフェードすることを避け、直前の表示から新しい画像へ切り替える。読み込み済みの中間レベルがある場合は、それより粗い画像へ戻さない。

## 選択地点・座標から景色を見る

標高のある地点を選び、マップ右上の「選択地点から見る」を押す。地点ファイルがなくても、地図をクリックして座標を選び「選択座標から見る」で切り替えられる。地形OFF・未読込でも利用でき、その場合は地形標高を0mとして扱う。

| 操作 | 景色モードでの動作 |
|---|---|
| 左ドラッグ | 現在位置を固定し、掴んだ地形がカーソルに追従するよう見回す |
| 右ドラッグの左右 | 方位を回転 |
| 右ドラッグの上下 | 視点を傾ける |
| ホイール | 視野角を変更 |
| Shift＋ホイール | 視点の高さを変更 |
| 俯瞰視点に戻る | 切り替え前のマップ視点へ戻る |

地点からの視点高は地点標高と地形標高の高い方、座標からの場合は地形標高に「加算する高さ」を加えた値。既定の加算は2m。右下に現在の視点標高を表示する。景色モードへ入ると加算高さを既定値へ戻す。地点を選び直した場合は手動調整を引き継ぐ。

「地点名を常時表示」は景色モードでも使える。地形に隠れる地点の丸印と名前は表示しない。

## 表示スナップショット

F8を押している間の操作と表示状態を記録し、離した時点で保存する。操作記録なしで現在の表示だけを保存することもできる。保存・固定表示・再生・元ファイルの条件は[スナップショット](docs/snapshots.md)を参照。

## 描画の状態を確認する

右下にFPS・CPU処理時間・GPUメモリの統計を表示する。GPUメモリはこのアプリが確保している量で、GPU全体の使用量ではない。無操作時は描画を休むため、FPSは下がる。

「設定」のオンライン地図・地表・地形でタイル境界やレベル別の色分けを表示できる。不具合を報告するときはスナップショットとスクリーンショットを併用する。エラーログの保存先は[開発・検証・公開](docs/development.md#エラーログと性能診断)を参照。

## 配布版の公開

Releaseの作成と公開手順は[開発・検証・公開](docs/development.md#配布版の公開)を参照。

地形の着色は「設定」→「地形」の「標高別の色分け」チェックボックスで切り替えられます。OFFでは従来の陰影表示になります。標高別の色分けは低地を緑、高地を茶色から白へ連続的に変え、地形の陰影も適用します。このモードではオンライン地図・地表画像より地形の標高色を優先します。「初期値に戻す」で陰影表示へ戻ります。

景色モードで地点の丸印にマウスを重ねると、地点名・現在の視点位置からの地表距離・所在地（都道府県など）を表示します。距離は1km未満ではm、それ以上ではkmで表示します。所在地は地点一覧と共通です。

「設定」→「描画」で霞の表示と強さを変更できます。初期値はON・強さ1.0で、変更はすぐに反映され、次回起動時にも引き継がれます。霞をOFFにしても昼の空は維持します。

景色モードでは右下の視点標高にある−／＋で1mずつ上下移動できます。数値をクリックすると標高を直接入力でき、ドラッグでも微調整できます。

「設定」→「地形」の「GPUカリング＋間接描画（試験）」で、可視パッチのGPU選択を比較できます。初期値はOFFです。通常の地形描画が対象で、制御点TIN表示には適用しません。選択状態はスナップショットにも保存します。

「GPUで可視判定・分割計画（試験）」をONにすると、描画パッチの可視判定・分割・接合制約・三角形数の配分をGPUで行います。この場合は追加カリングを省きます。初期値はOFFです。重い計画処理を並列化し、CPUへの読み戻しも必要な範囲に絞ります。比較検証用の設定です。結果と制約は[描画の技術資料](docs/rendering.md#gpu分割計画の比較)に記載しています。
