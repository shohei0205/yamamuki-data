# 粗いMLSのLPF目標と曲率抑制

2026-10-27。

## 目的と比較条件

元DEMを少ない制御点で直接適合すると、細かな起伏を追うために人工的な陰影模様が出る。元DEMをLPFした曲面を適合目標とし、補間・適合由来の波打ちも抑える比較を追加した。既存データは保持し、上書きしない。

対象は富士山・槍ヶ岳・筑波山の32 km四方。50～3,200 mの独立MLSを比較する。50 m等は標高方向の目標差であり、LPFの水平幅ではない。制御点は既存と同じ自由配置XY、点数も同じ。保存形式MLQ1、復元MLS、XY量子化0.0625 m、Z量子化候補は従来どおり。

| 表示方式 | 適合目標 | 曲率抑制 |
|---|---|---|
| 従来・未処理DEM | 元PNG DEM | なし |
| LPFのみ | Gaussian LPF後のDEM | なし（50 mの比較用） |
| LPF＋曲率抑制（弱） | 同上 | λ=1/目標誤差、50～3,200 m |
| LPF＋曲率抑制（強） | 同上 | λ=5/目標誤差、50 mの比較用 |

## LPF

Gaussianの標準偏差は `sigma = 0.25 * 32000 / sqrt(制御点数)`。距離はWebメルカトル上のm。50 m・8,192点ではσ=88.388 m。σを4倍した距離と元画素2個分を32 km範囲の外側へ追加し、周辺の元PNGも読み込んでからフィルターをかける。端で範囲を打ち切った平滑化をしない。フィルターの打切りは4σ。

欠損を0 mと混ぜないため、有限画素の標高と有効重みを別々にフィルターし、最後に重みで割る。元の欠損画素は欠損のまま保持する。固定格子は目標を計算する元DEMと描画用の一時データだけで、保存する制御点は自由配置のまま。

この幅は平均点間隔を基準にした比較用設定。最適値の保証や、元DEMに対する誤差目標の保証はない。

## 曲率抑制

各制御点について近傍12点の重み付き一次面を作り、その中心への予測値と制御点Zの差をL行列で表す。距離を正規化し、重みは逆二乗（近傍距離の下限0.1）。定数と傾斜した平面をほぼ消去し、一次面からの曲がりを罰則にする。実際の連続曲面のHessianを直接計測する罰則ではなく、制御係数の近傍一次面からの逸脱を抑える方法。

適合の目的関数に `lambda * Lz` の二乗和を追加する。従来は補正を8回まで累積していたが、抑制ありでは毎回LPF目標をサンプルした初期Zを中心に解き直す。LSMRのdampは0.003、最大500反復。誤差重みの倍率上限は従来・LPFのみの24に対し抑制ありは8。高さの誤差が最良だった反復を保持する。

強い抑制は細かな模様をよく減らすが、尾根や谷まで丸めて形状誤差が増えたため、弱い抑制を標準比較候補とした。両方とも保存して比較できる。

## 評価を分ける

圧縮データを復元して、各地域の元PNG画素中心11,222,500点すべてで評価する。

1. 元PNG DEMとの差（従来と同じ基準）
2. LPF目標との差（今回の適合目標）

それぞれ最大差・中心2 kmの最大差・RMSEを保存する。`converged`は元DEM基準のまま、`filteredTargetValidation.converged`はLPF目標基準。画面のLPF目標達成/未達表示は後者で、元DEM誤差を隠さない。元DEM自体の測量上の精度に対する保証ではない。

別の診断として山頂周囲8 kmを512分割で評価し、曲面とLPF目標の差からσ32 mのGaussian低周波を引き、その高周波成分の勾配RMSを測る。細かな陰影の不一致を比較する代理指標であり、視覚品質の保証ではない。

50 m版のこの診断値は、弱い抑制で従来比56～61%減少した。LPF目標への標高RMSEも従来比で低下。LPFのみの方が標高誤差は小さいが細かな模様が残り、強い抑制は模様がさらに減る一方で形状誤差が増える。

## 実行とデータ

```powershell
# 50 mでLPFのみと強い抑制を比較
build/terrain-venv/Scripts/python.exe -X utf8 tools/terrain/mls_lpf_dem.py --pilot --errors 50
# 弱い抑制を全粗段階へ適用
build/terrain-venv/Scripts/python.exe -X utf8 tools/terrain/mls_lpf_dem.py --errors 50 100 200 400 800 1600 3200 --output build/mls-lpf-dem-v2 --curvature-factor 1 --variant lpf-balanced
build/terrain-venv/Scripts/python.exe -X utf8 tools/terrain/render_lpf_dem.py
build/terrain-venv/Scripts/python.exe -m unittest discover -s tools/terrain -p test_mls_lpf_dem.py
```

強い抑制とLPFのみの結果はbuild/mls-lpf-dem-v1、弱い抑制はbuild/mls-lpf-dem-v2。元PNGの範囲・ハローのSHA-256、生成条件、進捗、PID、ログを記録する。configuration.jsonが異なる条件での再開は拒否する。比較画面は http://127.0.0.1:61484/dem-lpf/ 。左側を元DEMとLPF後の目標で切り替えられる。生成方式と品質を切り替えても視点は保持する。

## 補間半径の修正

LPF後も残る細かな模様に対し、補間半径の勾配不連続を解消する方式を追加した。生成方式「LPF＋滑らかな補間半径（新）」で比較する。点XYZと圧縮BLOBは同じ。復元規則とメタデータはMLS_SMOOTH_RADIUS.mdを参照。表示時の地形をBスプライン化したものではなく、MLS評価で用いる支持半径だけを滑らかにしている。
