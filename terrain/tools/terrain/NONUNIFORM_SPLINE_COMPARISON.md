# 不等間隔 B スプラインの比較

等間隔の制御点配置をやめる比較。元の保存 B スプラインを、曲率と再現誤差に応じた不等間隔のノット列で近似する。

http://127.0.0.1:61478/?region=yari&keep=0.0625&lpf=0

## 配置と制約

X と Y のノットを別々に配置する三次のテンソル積 B スプライン。間隔は不均一だが、直交した行と列は残る。任意の XY へ独立した点を配置する方式ではない。表示の「保存係数の位置」はノットから求めた Greville 点に高さ係数を付けたもので、曲面上の補間点とは限らない。

元曲面を 62.5 m 間隔の 513×513 点で評価。二階差分の大きさを各軸へ集計して配置密度を作る。密度を標本 3 個分の Gaussian でならし、平均密度で正規化した後、0.25～3 に制限する。密度の累積分布の分位点へ内部ノットを置く。境界は開いた三次 B スプラインとして端点を 4 重にする。

ノットを固定し、各軸の基底行列の擬似逆行列で高さ係数を最小二乗近似する。再現残差を各軸へ集計して密度を更新し、3 回のうち標本高さ RMSE が最も小さい結果を採用。擬似逆行列の特異値の相対打切りは 1e-4 とし、強い密集による数値不安定性を抑える。山頂の厳密な保持や連続領域の最大誤差は保証しない。

係数予算は以前の比較の 1,369＋floor(67,081×割合) を使用し、その平方根の整数部分を各軸の係数数にする。100・50・25・12.5・6.25% は各軸 261・186・134・98・74 個。等間隔版とは方式が異なるため、割合は同じ予算の目安であり、削除済み係数の残存率ではない。

## 保存と表示

build/nonuniform-spline-v2/nonuniform.sqlite3 の surfaces に region, keep, info, knotsX, knotsY, coefficients を保存。主キーは (region, keep)。ノット 2 列と高さ係数の little-endian float32 を、それぞれ zlib level 6 で圧縮する。容量はこの 3 本の BLOB の合計で、SQLite と info は除く。

表示時は互換性のため、保存した不等間隔曲面を 125 m 格子の既存 GPU B スプライン基底へ最小二乗で再構成する。これは保存する制御点の配置ではなく描画用の一時データ。不等間隔曲面との再構成誤差を画面に表示する。現状の 15 条件では標本上の最大差が約 0.9～9.3 m あり、厳密な直接描画ではない。法線角度差は未測定なので表示しない。

槍ヶ岳 6.25% は 74×74＝5,476 係数、圧縮 19,897 B。元の保存曲面に対する標本高さ RMSE は 27.01 m、GPU 再構成による標本最大差は約 1.00 m。元 DEM への誤差ではない。

等間隔版、孤立係数削減版、元データは保持。全国生成には適用していない。最初の試作 v1 は筑波山の高密度設定で数値不安定性が出たため比較には使わず、特異値の打切りを加えた v2 を使用する。

## 再現

```text
python tools/terrain/nonuniform_spline.py generate
python tools/terrain/nonuniform_spline.py serve
python tools/terrain/test_nonuniform_spline.py
node tools/terrain/test_nonuniform_spline.cjs
```

単体テストはノットが不等間隔であること、基底の非負性と分割の和、平面の保持、全保存データの数値安定性と表示再構成誤差を確認する。ブラウザーでは 3 地域×5 設定と保存係数の表示を確認する。
