# 自然近傍・タイル境界と混合品質の接合試験

2026-10-27。採用済みの親XY保持・NSP1・独立アンカー800/400/50 mのデータを使い、同品質、異なる品質、T字、一部境界、未読込を確認する画面を追加した。接合方式そのものは比較試験であり、採用決定とは区別する。

## 対象と配置

富士山・槍ヶ岳・筑波山の既存32 km四方モデルをタイル分割する。品質は許容誤差12.5～800 m、ズーム番号ではない。

- 8 km四方×4: A左上、B右上、C左下、D右下。範囲は各軸-8～8 km。
- T字: Aは左16 km四方 `[-16000,-8000,0,8000]`。Bは右上8 km四方、Cは右下8 km四方。Dは使わない。
- 一部境界: T字のBまたはCを未読込にすると、Aの右辺の半分だけが他タイルに接する。
- 各タイルは個別に品質または未読込を選択。全タイル未読込も許す。

同品質の試験は同一の地域モデルから分割したもので、各タイルを別々に生成した場合の一致や独立した作業領域同士の接合を確認したものではない。

## 余白と同品質の一致

1. タイル本来の範囲を最大接合幅2 kmだけ拡張する（元地域の凸包を超えない）。
2. 元モデルのDelaunay各面について、外接円がこの照会矩形と交差する面を集め、その頂点を選ぶ。照会点の自然近傍候補を取り落とさないための選択。
3. 選んだ頂点のDelaunay隣接点も含め、元Voronoiセルの境界を再現する。
4. 粗い品質で保存した同じタイルの全XYも引き継ぐ。現在の品質のZで取り直す。
5. 各タイルを独立にSibsonSurfaceへ復元し、分割前の地域曲面との一致を確認する。

3地域×7品質×5タイルの105モデルを保存。各タイル8,192ランダム点で確認した最大差は約1.48e-10 m以下。共有辺の直接評価も全品質で1e-5 m以内に一致した。同品質だけが読み込まれている場合は混合の計算を省き、そのタイルの曲面を直接使う。

ここで2 kmは照会・混合帯の最大幅であり、保存点を本来範囲から2 km以内に制限する意味ではない。影響を持つ面と隣接点、親XYを保持するため、遠方の少数点も含む。今回の最大領域外距離は約10.6 km。保存余白の最小化は未実施で、画面の試験条件とmanifestで点数・距離を確認できる。

## 保存形式

地域ごとに `build/sibson-seams-v2/{region}/tiles.sqlite3` を作る。表は既存の `levels` で、regionキーは `{region}:{tileName}`。800・400・50 mは独立MLQ1、他はNSP1で直近の粗い品質を参照する。余白にも親XY包含を保ち、SHA-256で復元XYZを検証する。

本来範囲と評価用範囲はmanifestへ保存。`corePoints`、`haloPoints`、`maxOutsideDistanceMeters`、独立換算`bytes`、実際の`storedBytes`、`parentError`、分割前との差も記録する。画面の「単体BLOB」は表示品質単体の形状ペイロードで、親込み量や描画用場の転送量ではない。

元の生成物とv1の切出し試験も保持する。v1は各品質で切り出した点を独立に保存した試作で、v2が現在の画面の入力。

## 異なる品質の接合

読込済みタイルごとに本来範囲を境界として、5次smoothstep `S(t)=6t^5−15t^4+10t^3` を各軸の両端に適用する。片側幅Wは250・500・1000・2000 m。範囲内外の距離に応じる重みを4辺で掛け合わせる。

同じ世界座標では所有タイルに関係なく、同じ読込集合の重み付き曲面を使う。

`H = Σ(w_i h_i) / Σw_i`

傾きは高さの重み付き平均だけにせず、重みの微分も含める。

`∇H = [Σ(w_i ∇h_i + h_i ∇w_i) − H Σ∇w_i] / Σw_i`

これでT字や4タイルの交点も、一つの共通の曲面を各タイルへ割り当てられる。未読込のタイルの重みは含めず、読込済みだけで正規化する。隣接が1枚しかない開いた辺では、その曲面を0 mへ減衰させない。

異品質の境界帯では両側の形状を混ぜるので、細かい側の指定最大誤差をそのまま保証する方式ではない。接合帯での元DEM最大誤差の再検証・細部の保持・接合幅の最適化は未実施。自然近傍は制御点上の傾き連続も一般には保証しないため、曲面全体のあらゆる点でC2になると主張するものではない。

## 描画と測定

- 保存タイルを31.25 m間隔で事前評価し、高さ・勾配の描画用場を作る。配布する形状の保存格子ではない。
- ブラウザは派生した場を読み、接合帯を計算して表示する。元の全地域モデルを読み込んで描いているのではない。
- 全タイルの描画間隔は31.25 mでそろえる。大きさは16/8 kmで異なるが、GPU描画の分割間隔が異なる場合のT頂点・縫い目対策はこの試験に含まない。
- 地形の色・陰影は従来の比較画面と同系統。境界線・タイル色をON/OFFできる。
- 更新中は旧GPU表示を保ち、新しい全タイルの準備後にまとめて切り替える。ドラッグ・回転は描画だけで、接合を毎回再計算しない。

## 独立生成した隣接タイルの追加試験

- 画面: http://127.0.0.1:61484/dem-natural-independent-seams/ 。以前の切り出し版も保持する。
- 生成器: `generate_sibson_independent_seams.py`。3地域×7品質×5矩形を別々に適合する。隣接タイルの制御点や生成済み地域モデルは初期点にも用いない。
- 各保存領域を片側2 km広げた矩形を生成範囲とし、その内部の元PNGの全画素中心で最大誤差を検査する。初期点はこの矩形内の1 km格子だが、最終保存は誤差位置に追加した自由XYZであり、高さ格子は保存しない。粗い品質の容量最適化は今回の目的に含めない。
- LPF幅だけは既存の地域・品質別の監査済み値を共用する。入力DEMとLPFは同一にし、点配置と適合をタイルごとに独立させる。
- 同品質でも境界値は一般に一致しないため、単一タイルを除き接合帯で共通化する。同品質の混合省略は適用しない。重みと勾配式、未読込の扱い、描画間隔31.25 mは先の試験と同じ。
- 全品質を単体MLQ1で保存する。今回は親XY包含・NSP1圧縮は適用しない。容量を従来の差分圧縮版と直接比較しない。
- 生成前の各タイルの誤差条件と、接合後の境界連続性は別の検証である。接合帯内での最大誤差保証と異なる描画分割数への対応は未確認。
- 元地域32 km内で独立適合する試験であり、全国の任意座標の独立生成を確認したものではない。

### 独立生成試験の確認結果

- 全105タイルを生成済み。量子化後の曲面を各矩形内の元PNG全画素中心と比較し、全タイルで品質別の最大誤差条件を満たした。
- Chromeで45ケースを確認。接合を有効にした共有境界のfloat32描画頂点の高さ差は0 m、法線角の数値差は約0.0000012度以下。接合なしのケースは意図どおり差が残る。JavaScript・WebGLエラーなし。
- 同品質12.5 mでも独立生成の境界高さ差は、富士山10.865 m・槍ヶ岳9.675 m・筑波山8.261 m。接合後はいずれも0 m。
- Pythonの任意矩形外周・全生成物監査の2テスト、および既存の接合・保存復元の3テストに成功。
- 境界帯の固定乱数点による表示場の追加監査は66ケース。片側250 m・同品質12.5 mの接合による高さ変化は、富士山最大4.070 m、槍ヶ岳4.026 m、筑波山3.411 m。接合が完全に無変更という意味ではない。
- 片側250 m・800 mと12.5 mの部分接合では、接合による高さ変化は槍ヶ岳で最大139.043 m。粗い曲面の影響は残るため、細かい側の誤差保証を維持する方式とは区別する。
- 表示場は31.25 m間隔の派生データである。12.5 m同士の境界帯の乱数監査で、接合前から富士山最大16.379 m・槍ヶ岳15.450 mの誤差がある。生成曲面の元PNG画素中心の監査と、表示場の任意座標の誤差を混同しない。
- 記録: `build/sibson-independent-seams-v1/browser.json`、`blend-audit.json`、各地域の `tiles.sqlite3`・`progress.json`・各タイルの `iterations.json`。

## 保存余白0 mの比較試験

- 生成器: `generate_sibson_no_overlap_seams.py`。保存先 `build/sibson-no-overlap-seams-v1`、画面 `/dem-natural-no-overlap-seams/`。以前の2 km余白版は保持する。
- 3地域・7品質・5矩形を、本来のタイル範囲内だけで独立適合する。自由XYZはすべてタイル内、描画用の場もタイル内だけ。保存余白点は0。LPFの生成元DEM参照のための範囲と、配布形状の余白は区別する。
- 初期辺上の点が共通の1 km座標に置かれるため、同品質では高さが一致しやすいが、傾きは独立生成により異なる。
- 初期表示は「接合なし」。接合ONは、隣接タイルの端の高さ・傾きから実行時だけ線形外挿し、既存の正規化重みで共通曲面を作る試験。領域外の形状データを保存・取得することはない。
- 外挿した高さの曲面を1 mの中心差分で評価し、その勾配で陰影を付ける。外挿先の実地形を復元する保証はなく、大きな補正帯では誤差が増え得る。保存余白なしと、無補正は別の選択肢である。
- 配置・未読込・全品質・接合ON/OFFを2 km余白版と同じ条件で比較する。描画間隔は引き続き31.25 m。

### 余白0 m・境界監査版（v2）

- 採用前の比較画面: http://127.0.0.1:61484/dem-natural-no-overlap-seams-v2/ 。`generate_sibson_no_overlap_seams_v2.py` から生成する。最初のv1は残す。
- 元PNG画素中心の誤差検査に加え、タイルの4辺上も元DEM画素間隔以下（約9.55 m以下）の間隔で評価する。境界の補間誤差が大きい点も適合時の追加候補に含める。
- 105タイルで、タイル内の元DEM画素中心と4辺の評価点の最大誤差条件を満たした。保存点がすべて本来の矩形内、保存余白点0、表示用場の範囲も矩形と等しいことを自動検査済み。
- 表示場31.25 m間隔に由来する誤差は別に残る。元DEM画素中心・辺上の標本検査を、連続域の最大誤差保証とはしない。
- 66ケースで補正帯の固定乱数点を測定。富士山12.5 m同士で、片側250 mでは最大表示誤差が接合前16.963 m→接合後34.445 m、形状変化は最大32.093 m。片側2000 mでは16.963 m→289.869 m、形状変化292.818 m。

- 保存BLOB合計は799,741 B、保存点合計165,389（3地域・7品質・5矩形、重複込み、全独立保存）。旧v1は795,609 B・164,895点で、境界監査追加の容量増加は約0.52%。既存の親XY差分版とは形式条件が違う。
- データ・測定記録は `build/sibson-no-overlap-seams-v2/`。比較画面は初期状態「接合なし」とし、外挿の接合を明示的に選べるようにする。

余白0 m・境界監査v2のChrome表示45ケースに成功。共有境界のfloat32描画頂点の高さ差0 m、JavaScript・WebGLエラーなし。これは連続性の検証であり、単純外挿の形状品質を採用可能とする意味ではない。
