# 自然近傍補間の比較

2026-10-27。狭い二次 MLS の負の係数による凹みを避けるため、Sibson 自然近傍補間を追加した。

## 方式と実装

- 保存する形状は自由配置 XYZ。8,192 点・16,384 点を富士山、槍ヶ岳、筑波山で生成。
- XY は `mls-xy-placement-v1` と同じ。Z は同じ LPF 目標（Gaussian σ=88.38834764831843 m）から直接取得し、0.125 m 刻みに量子化。既存 MLS の Z は再適合した係数なので、補間式以外にも差がある。
- Delaunay 三角形分割から照会点を含む外接円の領域を探索し、自然近傍の点を求める。照会点の Voronoi セルと各既存セルの重なり面積を半平面切断で計算し、面積を正規化して高さを混ぜる。Laplace 座標や単なる逆距離加重ではない。
- 半径、固定近傍数、標高格子は使わない。三角形情報は実行時に XYZ から導出する。凸包の辺上はその辺の線形補間になる。
- C の倍精度計算を Python ctypes から呼ぶ。セルの初期外枠に触れた場合は拡張して再計算し、外周近くの細長いセルを人工的に切らない。固定長配列の上限を超えた場合はエラーにし、別方式に黙って切り替えない。
- `SibsonSurface` は本試験の中心原点±16 kmの領域を想定する。凸包外はエラー。任意領域用の一般ライブラリ化は未実施。
- 非負の面積比なので、自然近傍の高さの最小～最大を超える暴走はない。実際の地形の峰・谷がその範囲を超える場合は逆に再現できない。点上では傾きの連続性を保証しないため、少し角張りが残る。
- 表示時の追加平滑化は行わない。従来画面と同じ 1025² の描画用場を生成し、勾配を有限差分で計算する。この場は確認用派生データで、モデル容量に含めない。

## 実測

次は山頂周辺 8 km の診断。RMSE は LPF 目標との差、細かい荒れは誤差の 32 m 高域成分の傾き RMS。これは全域の最大誤差ではない。

| 地域 | 点数 | モデル KiB | RMSE m | 細かい荒れ |
|---|---:|---:|---:|---:|
| fuji | 8,192 | 44.0 | 6.40 | 0.01306 |
| fuji | 16,384 | 84.4 | 3.55 | 0.01436 |
| yari | 8,192 | 45.5 | 21.21 | 0.02902 |
| yari | 16,384 | 87.6 | 12.41 | 0.03315 |
| tsukuba | 8,192 | 42.4 | 5.71 | 0.01220 |
| tsukuba | 16,384 | 81.2 | 3.28 | 0.01392 |

槍ヶ岳の 8,192 点版では、細かい荒れの指標が再配置 MLS の 0.09941 から自然近傍の約 0.02902 へ低下。目視でも深い凹みは減ったが、制御点付近の角張りは残る。Z の取得方法も違うため、補間式だけの改善率とは解釈しない。

全域外周では点が不足し、凸包辺が四隅を結ぶため最大誤差が大きい。現配置のままで 50 m 最大誤差を達成したとは扱わない。画面に全域の実測値・未達を表示する。実用化時には外周の制御点配置と隣接領域を含む評価が必要。

## 点数連動の生成時 LPF

2026-10-27。固定 σ88.388 m 版を保持し、点数連動版を 3 地域×8段階で追加。σ=32,000 / sqrt(制御点数) / 4 m とする。低点数ほど元 PNG DEM を強く LPF する。表示時の平滑化ではない。

| 制御点数（32 km 四方） | Gaussian σ |
|---:|---:|
| 16,384 | 62.50 m |
| 8,192 | 88.39 m |
| 4,096 | 125.00 m |
| 2,048 | 176.78 m |
| 1,024 | 250.00 m |
| 512 | 353.55 m |
| 256 | 500.00 m |
| 128 | 707.11 m |

同じ点数の固定版から XY をそのまま引き継ぐ。LPF による変化だけを比較するため配置は最適化し直さない。Z は各 LPF 目標から取得し 0.125 m に量子化。1/16 m の XY 刻み、自然近傍の復元式、描画解像度は共通。

目標画像は `filteredTargetKey` でモデル別のキーを明示する。例えば 128 点は `50-target-scale-128`。従来の固定幅 `50-target` を上書きしない。元 DEM の表示は全方式で共通。固定幅と連動幅で「LPF目標との差」を比べると目標自体が異なるため、元 DEM の誤差も併せて見る。

比較画面の「生成時LPF」で「固定 σ88.4 m」「点数に連動」を切り替える。左側が「LPF後の目標」の場合は目標も選択幅に変わる。視点とワイヤー設定は保持し、URL の `lpf=scaled` で再現する。MLS 選択時は固定幅のみなので LPF 選択を無効にする。

低点数では小さい山を LPF 自体が削る。これは狙った低域化の結果であり、山頂保持の達成を意味しない。この σ の式は比較用の仮設定で、最適値と判断していない。

- 生成: `python tools/terrain/generate_sibson_scaled_lpf.py`
- 出力: `build/sibson-scaled-lpf-v1/`。固定幅版は保持。
- 各モデルを元 PNG の 11,222,500 点で検証済み。
- ブラウザ: `test_sibson_scaled_browser.cjs` で3地域×8段階×2LPFの48ケース成功。参照キー、σ、ワイヤー、視点保持、JavaScript / WebGL エラーを確認。
- 保存・復元: `test_sibson_scaled_lpf.py` で固定版とのXY一致、点数、σ、Zの量子化、検証件数、描画高さ、モデル別LPF目標、固定目標非上書きを確認し成功。8,192点は固定幅と同じσ・同じ保存点であることも確認済み。
- URL: http://127.0.0.1:61484/dem-natural/?region=tsukuba&variant=natural-128&reference=dem&lpf=scaled
