自然近傍・差分圧縮比較

子の XY はそのまま保存し、高さは親の自然近傍曲面からの差分で保存します。親の予測を 0.125 m 刻みの整数に丸めてから差を取る可逆方式です。全21モデルで保存点と復元曲面が一致し、追加誤差は 0 でした。

全段差分は800 mを独立保存し、400→200→100→50→25→12.5 mを順に参照します。アンカー併用は800・200・50・12.5 mを独立保存し、中間だけを差分化します。容量は全レベルを保存する場合と、あるレベルを単独で開く場合で区別します。

復元時間はこの Windows 上の Python＋ネイティブ C による3回の中央値です。BLOB展開、親曲面の構築・評価、最後の子曲面の構築を含みます。モデルのキャッシュなしで開始しますが、OSのファイルキャッシュは排除していません。ブラウザ・スマホでの速度ではありません。

比較ビューワーの描画は従来の事前計算データを使っています。このページは差分デコーダーのブラウザ実装ではなく、実際に生成・復元した圧縮試験の結果です。XYZ完全一致により従来の元DEMに対する誤差を維持します。
