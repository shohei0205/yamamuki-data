# 局所 RBF と滑らかな合成の比較

2026-10-27、61485 の補間方式に method=rbf を追加した。元の保存点を流用し、元 SQLite と生成処理は変更しない。

## 方式

自由配置の XYZ を入力し、最遠点法で約24点あたり1個、最大256個の領域中心を選ぶ。各中心の近傍48点以内から正規化座標で薄板スプライン RBF を作る。一次多項式を併用し、smoothing=0.002 で完全一致を緩める。

各領域の半径は、中心群による制御点の最大被覆距離の1.5倍、各近傍の最大距離の0.85倍、1 m の最大。重みは Wendland C2 の (1-r)^4(4r+1)、r<1。重みの和で正規化して曲面を合成する。三角形単位の補間ではない。

サーバーで高さと各軸1 m差分の勾配を評価し、ブラウザーは通常のポリゴン描画を行う。画素ごとの自然近傍計算は使わない。係数の配布形式と GPU 直接評価は未実装。表示用の格子は従来同様に一時生成のみ。

## 検証と限界

平面再現と滑らかな山形の二階差分の連続性テストに成功。槍ヶ岳・富士山の代表タイルで有限値を確認。槍ヶ岳100 mの12可視タイルでRBF取得とWebGLエラーなしを確認した。代表128分割の初回評価は槍ヶ岳約0.32秒、富士山約0.26秒であり、現実装の準備時間は自然近傍より速いとは言えない。

制御点は自然近傍向けに生成したものなので、RBFによる元DEMの誤差保証はない。余白点集合に依存して領域中心と係数も変わるため、同品質のタイル境界で曲面・勾配の一致は未保証。近似によるピーク低下と不要な凹みを目視判定する必要がある。表示前の強い平滑化や出力高さのクリップは行わない。
