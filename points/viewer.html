使い方

地点名を選ぶと地図と JSON 全文を表示します。地点一覧の行をダブルクリックすると補足編集画面を開きます。列見出しをクリックすると昇順・降順に並び替えます。一覧をクリックしたあと、↑・↓キーでも表示順に地点を選べます。JSON ファイルを選択して別の地点データも確認できます。

指定した地点データをもとに生成した一覧です。OSM の現在の登録内容はリンク先で確認してください。

タグ一括追加


先に地点 JSON を開き、山の一覧を入力してください。タグ名は追加するときに必要です。山名・別名で一致する地点を補完します。同名の候補が複数ある場合は、すべて対応表に追加します。




1 行に 1 地点。地点名のみ、osmId のみ、ID と地点名の 2 列に対応します。id を指定する場合は #id,name の見出しを付けてください。CSV または表計算ソフトからの貼り付けが使えます。見出しは省略できます。







候補を選ぶと地点名と ID が入ります。候補がない行は検索するか直接修正してください。不要な行は「除外」にチェックを入れ、最後に再照合します。


行・状態地点名・ID候補を選択・検索除外

追加したタグも同じタグ名で絞り込めます。同名タグの既存の地点を残して追記し、同じ地点は重複させません。元の JSON は変更しません。
