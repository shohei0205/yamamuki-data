使い方

地点名を選ぶと地図と JSON 全文を表示します。列見出しをクリックすると昇順・降順に並び替えます。一覧をクリックしたあと、↑・↓キーでも表示順に地点を選べます。JSON ファイルを選択して別の地点データも確認できます。

指定した地点データをもとに生成した一覧です。OSM の現在の登録内容はリンク先で確認してください。

タグ一括追加


先に地点 JSON を開き、山の一覧を入力してください。タグ名は追加するときに必要です。山名・別名で一致する地点を補完します。同名の候補が複数ある場合は、すべて対応表に追加します。




1 行に 1 地点。山名のみ、osmId のみ、osmId と山名の 2 列に対応します。CSV または表計算ソフトからの貼り付けが使えます。見出しは省略できます。







候補を選ぶと山名と osmId が入ります。候補がない行は検索するか直接修正してください。不要な行は「除外」にチェックを入れ、最後に再照合します。


行・状態山名・osmId候補を選択・検索除外






確認が必要な行がある間は追加できません。修正欄で直して再照合するか、元の一覧を修正してください。




追加したタグは (タグ JSON) として表示します。同名タグの既存の地点を残して追記し、同じ osmId は重複させません。元の JSON は変更しません。
