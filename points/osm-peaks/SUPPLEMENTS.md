# osm-peaks の地点補足

タグ・よみがな・別名・表示名の補正と地点の除外は、[supplements.json](supplements.json) 一つで管理する。日本百名山の 100 地点もこのファイルに収録する。共通形式と編集手順は [補足 JSON の説明](../README.md#補足-json-を開く) を参照する。

## 山名と osmId の補完

```bash
PYTHONPATH=points/osm-peaks python -m scripts.supplements points/osm-peaks/supplements.json --points osm-peaks-source.json.gz --output points/osm-peaks/build/supplements.json
```

osmId がない行では `note` の山名・別名を完全一致で照合する。osmId があり `note` が空なら地点名をメモに補う。候補が複数ある場合は未解決とし、終了コード 1 を返す。形式の不備は終了コード 2。入力は変更せず、補足・補正・出典情報を出力へ引き継ぐ。補完には補足適用前の元データを使う。

## 日本百名山の採用地点

[日本百名山タグの採用方針と検証記録](HYAKUMEIZAN_AUDIT.md) に、2026-10-10 の照合結果、変更した 6 件、確認待ち事項を記録している。

[Wikipedia「日本百名山」の参照版](https://ja.wikipedia.org/w/index.php?title=日本百名山&oldid=111092405) の「著書順の山の一覧」をもとに、各山に対応する地点を 1 件ずつ収録した（2026-10-10 作成）。山名・別名、標高と位置を検証対象の osm-peaks 14,035 地点と照合し、JSON の `note` に地点を識別するためのメモを記載している。

山頂標識がある地点を優先する。最高地点と登山上の山頂が異なる場合は、山頂標識のある登山上の山頂を採用する。焼岳は北峰、大山は弥山を採用する。飯豊山は飯豊本山、那須岳は茶臼岳、丹沢山は丹沢山を採用する。利尻山・羊蹄山は標識位置と OSM 地点の対応が確認待ちで、従来の ID を暫定的に保持している。全 100 件について標識そのものの座標を確認済みという意味ではない。
