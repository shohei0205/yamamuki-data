# 日本百名山タグの採用方針と検証記録

[supplements.json](supplements.json) に収録する日本百名山タグの採用方針、2026-10-10 の見直し内容、未確認事項を記録する。現在の対応表は補足 JSON で管理し、本書の全件表は変更前の照合結果として保存する。

## 採用方針

各山の山頂標識がある地点にタグを付ける。最高地点と登山上の山頂が異なる場合は、山頂標識のある登山上の山頂を優先する。焼岳は北峰、大山は弥山を採用する。

OSM の山群の代表点と個別の山頂点が分かれている場合は、標識のある山頂に対応するノードを選ぶ。標識の紹介資料と OSM の山頂名・座標を照合して選定するが、OSM の座標と標識そのものの位置が厳密に一致するとは限らない。全 100 件の標識位置の確認は完了していない。

## 変更前の照合結果（2026-10-10）

- 100 件・100 個の異なる osmId があり、全 ID が検証対象の地点データと現在の OSM API に存在する。
- 山と溪谷社の日本百名山一覧の 100 山に対応する。欠落、重複した山、同名の別の山への取り違えは今回の照合では見つからなかった。山群と採用した峰の違いは下記のとおり別途確認した。
- 現在の OSM と検証対象のデータで、100 件の名前・座標・標高は一致した。
- 93 件は対応する国土地理院の山頂座標から 100 m 未満。7 件は 100 m 以上で、山全体の代表点と個別の山頂点が混在している可能性がある。
- 標高の差が 1 m を超えるのは男体山（OSM 2484.15 m / 国土地理院 2486 m）。山頂座標との差は約 28 m で、山の取り違えを示すものではない。標高値の採用根拠は別途確認が必要。
- タグの osmId と OSM の登録内容は変更していない。

100 m は精査対象を拾うための目安であり、正誤を決める基準ではない。「位置整合」は下記資料との整合を確認した意味で、現地測量や全山の地形図目視確認を行った意味ではない。

## 参照した資料と方法

1. [Wikipedia「日本百名山」の元データ参照版](https://ja.wikipedia.org/w/index.php?title=日本百名山&oldid=111092405)：既存の対応表の出典。今回の独立した検証には次の資料を使用した。
2. [山と溪谷社・YAMASTA「日本百名山スタンプラリー」](https://yamasta.yamakei.co.jp/info/hyakumeizan.html)：100 山の掲載を照合。並び順は著書順と異なるため山名と採用峰で対応付けた。チェックイン対象は登頂認定の規則なので、その位置をタグの唯一の正解とは扱っていない。
3. [国土地理院「日本の主な山岳標高（1003 山）」](https://web2.gsi.go.jp/kihonjohochousa/kihonjohochousa41139.html)：[2026-03-31 版 GeoJSON](https://www.gsi.go.jp/KOKUJYOHO/MOUNTAIN/1003zan20260331.zip) の山名・山頂座標・標高を照合。国土地理院は山群名と山頂名を区別している。
4. [OpenStreetMap API](https://wiki.openstreetmap.org/wiki/API_v0.6#Multi_fetch)：100 個のノードを一括取得して存在・名前・位置・標高を確認。全件表の ID は各ノードの確認ページにリンクする。差し替え候補の 6 ノードも API で存在と座標を確認した。
5. 環境省、文化庁、自治体・地域の公式観光情報：山群の主峰や最高峰、複数の山頂について個別に補強した（以下のリンク参照）。

距離は OSM 座標から国土地理院の最寄り山頂座標への概算水平距離（球面の局所近似、m 単位に丸め）である。最寄り点の山名も全件確認し、対象の山に対応することを確認した。国土地理院 GeoJSON は JGD2011、OSM は WGS84。測地系や測量地点の違い、小さな位置差を考慮し、数 m の差を誤りとは扱わない。標高は OSM の値と国土地理院の整数値をそのまま併記する。丸め・測定点・更新時期が異なるため、標高の小差だけでタグを不正とは判定しない。

## 山群名と山頂名の照合

乗鞍岳のタグを付けた「剣ヶ峰」1851367347 は、国土地理院の「乗鞍岳＜剣ヶ峰＞」から約 2 m。[環境省](https://www.env.go.jp/nature/nationalparks/list/chubu-sangaku/spot/) と [乗鞍岳の公式案内](https://norikuradake.jp/about/) も剣ヶ峰を最高峰としている。近くの「乗鞍岳」4317246954 へ移す理由はなく、現在の選択を維持するのが妥当。

飯豊山は飯豊本山、那須岳は茶臼岳、丹沢山は丹沢山という既存の採用方針を、山と溪谷社の一覧でも確認できた。立山は大汝山、鳳凰山は観音ヶ岳、九重山は中岳、大峰山は八経ヶ岳など、山群に含まれる個別の峰を採用している。八ヶ岳は赤岳、荒川岳は悪沢岳（東岳）で、山と溪谷社の一覧では個別の峰名が使われている。草津白根山から本白根山への対応は [内閣府の火山解説](https://www.bousai.go.jp/kohou/kouhoubousai/h22/07/volcano.html)、鳳凰山の最高峰の選択は [環境省の鳳凰三山紹介](https://kanto.env.go.jp/blog/2018/06/post-496.html) とも整合する。

大山は剣ヶ峰を採っており、国土地理院の最高点から約 7 m。登山で一般的に訪れる弥山とは異なる。[環境省の紹介](https://chushikoku.env.go.jp/park/daisen/viewpoint/mt_daisen/index.html) も両者を区別している。登頂記録向けの一覧と、山を表示するアプリの代表地点は同じとは限らない。
