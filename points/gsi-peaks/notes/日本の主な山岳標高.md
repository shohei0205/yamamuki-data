# 日本の主な山岳標高タグの作成手順

[タグごとの記録に戻る](../README.md#タグごとの記録)

## 使用した資料

[国土地理院「日本の主な山岳標高一覧（1003山）」の 2026 年 3 月 31 日版 CSV](https://www.gsi.go.jp/KOKUJYOHO/MOUNTAIN/1003zan20260331.csv) を使う。出典と利用条件は地点原本の `metadata.sources` に記録する。

## 対象と付け方

[地点原本](../gsi-peaks-source.json) のうち、一覧の索引番号を持つ `gsi-mountain-list:` で始まる全 1,059 地点に、原本に直接「日本の主な山岳標高」タグを追加する。資料名は「1003山」だが、別山頂の行も含むため対象は 1,059 地点になる。

山名から所属を推測せず、自然地名やベクトルタイル由来の ID には付けない。既存のタグ・補正・除外指定は保持する。原本のタグ情報と出典は、配布時に地点 JSON と manifest に反映する。

生成処理では CSV を読み込むときにタグを付け、ベクトルタイルとの統合後も引き継ぐ。単体テストで対象 ID の過不足を確認する。
