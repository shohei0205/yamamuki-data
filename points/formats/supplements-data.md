# 補足データフォーマット

[地点データの README に戻る](../README.md)

## 概要

補足 JSON の形式と各版の変更を説明する。

## 版について

補足 JSON の版は `schemaVersion` で確認する。現行版は `1`。ほかの形式の版とは独立して管理する。

版内の変更は `版1.1` のように小数点以下で区別する。小数点以下は文書上の番号で、JSON の版の値には含めない。

項目表の「版の履歴」は、フィールドの追加や変更があった版を示す。スキーマは版ごとに分けて管理する。

| 形式の版 | 機械検証用スキーマ | 規格 |
|---|---|---|
| 1 / 1.1 | [supplements-data-v1.schema.json](../schemas/supplements-data-v1.schema.json) | JSON Schema Draft 2020-12 |

## 項目

地点の補足情報は一つの JSON ファイルにまとめる。`schemaVersion`・`points` と、任意の出典一覧 `sources` を持ち、`points` の `osmId` で元の地点に対応付ける。地点ごとにタグ・表示名・よみがな・別名・除外を指定する。

例の出典情報は、実際に確認した資料とその利用条件に置き換える。Wikipedia では参照した版の固定リンクを記載する。タグを追加しない地点は `tags` を省略する。

### ファイル全体の項目

| 項目 | 型 | 内容 | 版の履歴 |
|---|---|---|---|
| `schemaVersion` | integer | 補足 JSON の形式の版。`1` | [版1] 追加 |
| `points` | array | 地点ごとの補足。`osmId` で元データと対応付ける | [版1] 追加 |
| `sources` | object | 任意の出典一覧。キーは出典 ID | [版1] 追加 |
| `sources.<出典ID>.source` | string | 任意の資料名・参照 URL | [版1] 追加 |
| `sources.<出典ID>.license` | string | 任意の利用条件 | [版1] 追加 |
| `sources.<出典ID>.attribution` | string | 任意の著作者表示 | [版1] 追加 |
| `sources.<出典ID>.changes` | string | 任意の加工内容 | [版1] 追加 |

### 地点ごとの項目

| 地点ごとの項目 | 内容 | 版の履歴 |
|---|---|---|
| `osmId` | 対応する地点。重複のない正の整数で、最大値は `9007199254740991`。必須 | [版1] 追加 |
| `tags` | 追加するタグの配列。元のタグを保って重複なく追記する | [版1] 追加 |
| `tagsRemove` | 元のタグから削除する値の配列。画面上のタグ削除も保存する | [版1] 追加 |
| `name` | 表示名を置き換える。空文字は使えない | [版1] 追加 |
| `nameReading` | よみがなを置き換える。`null` は元のよみがなを削除する | [版1] 追加 |
| `graphic` | `svg` に SVG 本文、任意の `scale` に表示倍率を指定する。元の画像を置き換え、`null` は画像を削除する。省略時は元の画像を保つ | [版1.1] 追加 |
| `aliases` | 追加する別名の配列 | [版1] 追加 |
| `aliasesRemove` | 元の別名から削除する値の配列 | [版1] 追加 |
| `exclude` | `true` で表示・配布対象から除外する | [版1] 追加 |
| `reason` | 補正理由。表示名の置き換え・除外・よみがなの削除・別名の削除には必須 | [版1] 追加 |
| `note` | 管理用の自由なメモ。地点名の置き換えや一致検査には使わない | [版1] 追加 |
| `expected` | 補正前に想定する `name`・`nameReading`・`aliases`。元データと異なる場合は適用を中止する | [版1] 追加 |

各項目を省略すると元の値を使う。空配列は追加・削除しない指定とする。同じタグや別名を追加と削除の両方に指定できない。タグ・別名・よみがなには空文字や前後の空白を使えず、配列内の重複も拒否する。各地点には `tags`・`tagsRemove`・`name`・`nameReading`・`graphic`・`aliases`・`aliasesRemove`・`exclude` のいずれかの指定が必要。

`sources` は出典 ID ごとに `source`（資料名・URL）、`license`（利用条件）、`attribution`（著作者表示）、`changes`（資料に加えた加工）を保持する。これらの属性は任意の文字列。複数の資料を補足 JSON 全体の出典一覧として登録できる。地点や項目ごとの出典指定は行わない。

## 読み込みと検証

`schemaVersion` が対応する版であることを確認し、`points` の `osmId` で元データの地点に対応付ける。不正な値・未知の ID・重複 ID・追加と削除の競合がないかを検証する。`expected` がある場合は元データと照合し、不一致なら適用を中止する。

補足 JSON の編集と保存は [地点データビューアの操作手順](../README.md#補足-json-を開く) を参照する。

### タグと出典の引き継ぎ

`tags` は「日本百名山」などの分類ラベルを持つ配列。OSM の元タグをそのまま収録する項目ではなく、データ作成者が分類を確認して付ける。山名から分類を推測しない。アプリは未知のタグを無視できるようにする。

対応表を使って生成する場合は、補足 JSON の `sources` を manifest.json の `supplementSources` にそのまま記録する。出典 ID はタグ名やファイル名とは独立して扱う。元の地点データの出典とライセンスも残す。各属性の意味は [manifest の共通仕様](../../formats/manifest.md#項目) を参照する。タグと出典情報はいずれも任意項目の追加で、地点データと manifest のスキーマの版は 5 のままとする。

## JSON の例

出典情報は説明用。実際に確認した資料と利用条件に置き換える。

### 版1.1

```json
{
  "schemaVersion": 1,
  "sources": {
    "山の資料": {
      "source": "参照した資料の名称・URL",
      "license": "資料の利用条件の名称・URL",
      "attribution": "資料の著作者表示",
      "changes": "山名一覧を抽出し、osmId・よみがな・別名を追加"
    }
  },
  "points": [
    {
      "osmId": 204683948,
      "note": "羊蹄山。確認用メモ",
      "tags": [
        "日本百名山",
        "北海道百名山"
      ],
      "nameReading": "ようていざん",
      "aliases": [
        "後方羊蹄山",
        "蝦夷富士"
      ],
      "graphic": {
        "svg": "<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"0 0 100 100\"><path d=\"M10 90 L50 10 L90 90 Z\"/></svg>",
        "scale": 1.5
      }
    }
  ]
}
```
